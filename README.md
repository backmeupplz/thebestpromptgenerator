# The Best Prompt Generator

[thebestpromptgenerator.com](https://thebestpromptgenerator.com): type what you want in plain English, watch the welding sparks, get your prompt back unchanged. A joke site with a real point: frontier models like Opus 5.5 read plain English better than any prompt template, skill pack or "you are a world-class engineer" incantation.

## How it works

It is a single static page, `docs/index.html`, with no build step and no dependencies, served by GitHub Pages from `docs/`. Open it in a browser to run it locally.

The share image `docs/og.png` (1200×630) is rendered from `src/og.html` with headless Chrome, and `src/icon.html` is the source of the app icon.
